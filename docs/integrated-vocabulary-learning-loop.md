# IELTS WordLab 连续词汇学习策略

## 产品原则

学习者前台只经历一条连续任务：同一个词从声音进入拼写，从拼写进入构词，再从自然搭配进入口语或写作。图片、词源、近反义、同音同形、分类和类比是按错误类型调用的学习工具，不是互不相关的小游戏入口。

本策略已完成 46 份本地教学资源的格式、用途与版权边界盘点（42 份 PDF、3 份 DOCX、1 套已解包 EPUB）；其中 24 份 PDF 可直接提取文本，18 份需要 OCR。内容抽取与逐条编辑仍按批次进行，因此不把“已经登记”写成“已经读完”。这些资源用于提炼教学方法和任务结构，不自动成为 IELTS 目标词表来源。

## 一词九步学习循环

1. **无提示预检**：先听、看语境或看中文尝试回忆，记录完全陌生、似曾相识和音形混淆。
2. **场景相遇**：在短场景中听到目标词，只建立一个核心义和一个高频搭配。
3. **观察形式**：关注音节、重音、拼写块、词性和必要的词根词缀。
4. **建立网络**：连接一个自然搭配和一个语法框架；核心词稳定后才加入近反义或上下义关系。
5. **判断阶梯**：从辨认、选择、匹配逐渐升级到分类、排序和类比。
6. **双向检索**：完成听音拼写、意义回忆英文、基础词生成正确形式；优先无提示回忆。
7. **控制性使用**：在新句中选择正确词形、搭配和语法框架。
8. **真实迁移**：通过口头复述、故事续写或原创句证明能独立使用。
9. **延迟回归**：换场景先盲测；失败后只给最小提示，再进入短时重测。

当前网页把这九步压缩成适合手机使用的四个连续关卡：

| 前台关卡     | 覆盖能力                   | 学习证据                             |
| ------------ | -------------------------- | ------------------------------------ |
| 声音与核心义 | 听辨、重音、跟读、核心义   | 能听清并完成自我对照，不等于稳定掌握 |
| 无提示拼写   | 声音到词形、完整拼写       | 首次盲写与所需提示层级               |
| 词形与构词   | 词性判断、屈折、派生、词族 | 能在句中选择并写出正确形式           |
| 搭配到表达   | 搭配检索、句法、受控写作   | 先回忆词块，再在完整句中使用         |

## 错误修复路线

专项练习由错误触发，完成后回到主学习链：

- **声音—词形**：听辨、重音、拼写、同音词、同形异义词。
- **构词工坊**：词性、屈折、派生、词族、词根和经核实的词源。
- **意义网络**：图片猜词、近义词、反义词、上下义、分类和类比。
- **语境与表达**：搭配、语法纠错、词块排序、造句、复述与口语任务。

错误记录应逐步从单一“对／错”升级为：听辨、重音、拼写、词义、词性、屈折、派生、搭配、句法和语域。图片选择题只能证明辅助识别；稳定掌握必须包含无提示检索、原创表达和延迟复习。

网页中的“智能补弱”不再让薄弱词机械重做全部四关。系统按“能力 ×
词条”排序近期错误、正确率、到期时间和提示后完成情况，只安排真正
薄弱的一关；例如同一个词听音已经稳定但拼写连续失败，就只进入听写
修复。修复成功后回到延迟复习，不把一次提示后完成记作稳定掌握。

## 提示与答案规则

- 首次作答不显示词长、首字母、答案图片或完整词族。
- 学生可以跳过；跳过记为“待帮助”，不判为掌握，也不揭示整组答案。
- 提示按最小信息逐级增加，先规则和音节，再给有限字母线索。
- 词族先预测和独立变形，完成后才解锁完整答案、四格图和复述故事。
- 历史词源、现代构词规则和 AI／学生创作的记忆故事分别标注；记忆故事不得冒充真实历史。
- 不强迫每个单词凑齐名词、动词、形容词、副词四种形式，只训练真实、常用且经过核实的词族。

## 搭配与表达

搭配从首次学习就作为一个整体保存和朗读，不等学完单词后再进入独立模块。句子工坊采用三步：

1. 不看答案，先口头说出或写下一个自然搭配。
2. 打开搭配卡核对，然后完成去除大小写和句末标点线索的词块排序。
3. 遮住标准骨架，按中文提示独立写出完整句子并自查。

## 图像和故事的作用

- 具体词可用场景图建立核心义；抽象词先用语境定向，再提供记忆图。
- 图片是检索线索，不是掌握证据；延迟测试应撤掉图片。
- 同一词族的四格图使用同一人物和因果链，支持名、动、形、副的口头复述。
- 近反义词在核心词已经能独立回忆后解锁，以对比语境辨析，不堆放孤立词表。
- 同音、同形、分类和类比进入对应错误修复路线，避免首次学习时制造额外干扰。

## 复习与掌握

推荐复习节点为：本轮交错复现、错误后 5–10 分钟、1 天、3 天、7 天、14 天、30 天、90 天。具体间隔由正确率、提示次数和反应时间动态调整。

掌握状态分六级：

1. 图片或选项辅助下认得。
2. 无提示识别词义和词性。
3. 能从意义或声音回忆正确词形。
4. 能在新句中完成词形和搭配。
5. 能在原创口语或写作中准确使用。
6. 延迟复习后仍能迁移使用。

听、说、读、写分别记录；同一词可以阅读稳定但写作薄弱。只有完成延迟测试，才标记为“稳定掌握”。

## 资源使用边界

- _How to Teach Vocabulary_ 与 _Assessing Vocabulary_ 用于总体练习顺序、词汇知识维度及测评边界。
- _English Vocabulary in Use_ 系列用于学习单元结构和由理解到使用的递进。
- 英语形态学与 _Building Vocabulary from Word Roots_ 用于区分屈折、派生、转换及词根迁移。
- _English Collocations in Use_ 用于把搭配前置为基本学习单位。
- _Elementary Vocabulary Games_、记忆与视觉词汇资源用于活动和检索线索设计。
- Edge、Scholastic、Wordly Wise、SSAT 等材料只提供年龄分层、支架和题型灵感。
- 任何标有 “Official” 的第三方书名都不自动获得官方资格；是否进入 IELTS 词库仍须核对真实出版方和来源证据。
- 不复制受版权保护的书页、插图、例句、题目或整套词表；网站内容应重新编写并保留词条来源证据。

## 教材方法如何汇入同一条学习链

| 资源类型                                            | 吸收的方法                           | 在网页中的位置                     | 不允许做的事                     |
| --------------------------------------------------- | ------------------------------------ | ---------------------------------- | -------------------------------- |
| Vocabulary in Use、学校分级词汇材料                 | 主题语境、由理解到使用的支架         | 核心义、控制性练习、年龄分层       | 直接把全书词汇称为 IELTS 必背    |
| Collocations / prepositions / phrasal verbs         | 把自然词块当作基本学习单位           | 第四关的无提示搭配检索与造句       | 复制原书例句和整页练习           |
| Morphology / word roots / Latin and Greek elements  | 屈折、派生、词族和可迁移构词规律     | 第三关词形判断、直接变形、词源彩蛋 | 把记忆故事冒充历史词源           |
| Visual vocabulary / games / picture cards           | 图像线索、对比、分类、类比和故事复述 | 词义混淆后的专项修复               | 复制原图、用图片选择代替掌握测验 |
| Assessing Vocabulary / memory / teaching references | 词汇知识维度、检索练习、延迟复习     | 错因记录、掌握等级、动态排期       | 从教学法正文抓词并加入目标表     |

这样每类材料只负责自己最擅长的一段：目标词由教师与可靠词表控制，
搭配和构词材料补“怎么用”，图片和游戏补“哪里混淆”，测评与记忆材料
决定“何时重测”。学生前台始终只看到一条连续学习路线。
