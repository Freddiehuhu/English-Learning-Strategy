# English Learning Strategy：Agent 协作与质量门禁

## 总控原则

主 Agent 是唯一集成负责人：决定优先级、核对专业 Agent 的证据、修改产品、运行完整测试并发布。专业 Agent 默认只读；只有任务明确划定独立文件范围时才可编辑。任何 Agent 的建议都不能自动进入网站。

并发成员保持精简，按阶段轮换。一个批次没有形成可核查交付前，不继续扩大成员数量。

## 专业岗位

| 岗位           | 主要职责                                                 | 必须交付                                   | 不得代替的证据                 |
| -------------- | -------------------------------------------------------- | ------------------------------------------ | ------------------------------ |
| 教材资料分析   | 每批精读 3–5 份资料，提炼题型、支架、反馈和记忆方法      | 文件哈希、实际阅读页码、方法卡、适用边界   | 只看目录、只抽文本、书名推断   |
| 词库与来源工程 | 抽取、规范化、去重、保留来源与页码，维护审核状态         | 可重复运行的脚本、测试、候选 TSV、来源审计 | 候选词数量不能代表编辑完成     |
| 学习引擎架构   | 把研究证据转成统一的 8–12 分钟学习状态机                 | 能力模型、排程规则、迁移方案、验收测试     | 功能菜单数量、点击时长         |
| 题目与语言编辑 | 核对词义、词性、搭配、答案唯一性、提示和例句自然度       | 逐题风险清单、修改稿、可靠词典证据         | AI 自行猜测或“看起来正确”      |
| 发音与听写质检 | 核对英美音、自然度、文件完整性和声音—拼写训练            | 音频清单、抽听记录、交互测试、替换建议     | 文件存在不等于声音自然         |
| 视觉语义设计   | 判断图片是否真正表达词义差异，避免文字泄题和无关装饰     | 画面教学目标、对比场景、无泄题检查         | 图片好看不等于能辅助记忆       |
| 手机与发布验收 | 检查 iPhone/WebKit、Android/Chromium、离线缓存和线上路径 | 真机尺寸测试、失败截图、线上哈希与发布状态 | 桌面浏览器通过不能代表手机可用 |
| 学习成效分析   | 定义延迟回忆、拼写距离、词形和原创句修正等指标           | 指标定义、事件边界、隐私与实验方案         | 连续天数、在线时长、点击量     |
| 独立质量监督   | 只读复核声明、证据、测试和线上版本                       | 红黄绿报告与阻塞清单                       | 参与实现后再自我批准           |

## 分批流水线

1. **登记**：确认文件身份、哈希、页数、可提取性和版权使用边界。
2. **精读**：资料分析 Agent 记录真实阅读范围，只提炼方法，不复制受保护的原题、例句或插图。
3. **设计**：学习引擎和题目编辑把一个高价值方法写成具体任务、反馈和掌握证据。
4. **实现**：主 Agent 只实现一个可完整体验的学习切片，并保留旧进度兼容。
5. **自动验收**：运行语料、单元、端到端、移动视口、离线和构建测试。
6. **专业验收**：题目、音频、视觉和手机 Agent 分别只检查自己的领域。
7. **独立复核**：监督 Agent 检查宣传文字是否超过证据、是否存在答案泄露或虚假掌握。
8. **发布**：只有阻塞项清零，才合并并发布同一提交；随后复核线上版本。

## 红线门禁

- 没有哈希、页码和阅读记录的资料不得标为“已仔细评估”。
- 抽出的词只能进入候选区；没有逐词编辑复核不得进入正式词库。
- 自评跟读、图片选择或提示后完成不得单独升级为“稳定掌握”。
- 新词必须先有无提示尝试；答案、首字母、大小写或完整词族不得提前泄露。
- 同一能力必须独立排程，不能因一个维度到期而机械重做全部项目。
- 跳过必须允许，且进入较早复习；不得扣命、羞辱或制造断签损失。
- 不使用无限滚动、自动下一关、随机宝箱、虚假限时或以在线时长为成功指标。
- 线上发布必须与通过测试和复核的提交一致。

## 每轮完成定义

一个迭代只有同时具备以下内容才算完成：

- 一份可读的改动说明；
- 对应代码或数据差异；
- 自动化测试结果；
- 专业 Agent 的领域结论；
- 独立监督没有未处理的红色阻塞；
- 已验证的线上地址，或明确说明尚未发布及原因。
