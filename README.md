# English Learning Strategy · 沪教版八年级上册 单词/短语 学习卡

一个面向初中生的英语学习网页应用：**267 条**词汇（单词 203 + 短语 64），自带**自然语音音频**、**中英对照例句**、**Anki 式卡片**、**掌握度练习**与基于 Phaser 的**听写射击任务**。

> 📖 教材：上海教育出版社《英语》八年级上册（Units 1–8）。教材词汇表以**英式发音**为标准。

#### 声形急救（首发版）

这是一条独立于大词库的短时补弱路线，先处理学生“见词读不出、听词拼不回、语境反应慢”的高频卡点：

- 学生两批清单共 464 个非空输入，其中第二批新增 22 份上报；经确认过的连写拆分后形成 465 份规范化报告，再把 3 个重复词的两次报告合并为 462 个唯一词头。合并后的有效分组为：194 条读音困难（编号 `1`，未编号也按此类）、111 条词义困难（`2`）、157 条读音和词义都困难（`3`）。重复报告只合并能力缺口，不覆盖原记录；例如 `pluse3` 仍保留在档案中，并以确认记录对应到 `pulse`。
- 公开页面提供 462 词总表，可搜索并按困难类型、审校和练习状态筛选。首发只开放 12 个经 Cambridge Dictionary 与 Oxford Learner's Dictionaries 逐词核对的练习词，另外 450 词仍明确标为待编题，不能把总表规模写成已发布练习量。两轮首发词为：`controversial`、`fountain`、`pronunciation`、`instant`、`certificate`、`squeeze`、`botanical`、`ridiculous`、`alcohol`、`architecture`、`distinguish`、`sculpture`。
- 每个词按学生标记进入“见词辨音”“盲听成形”“语境辨义”中的一门或多门；三门分别记录，不能用其中一门的成功替代另一门。`instant` 因原听力句缺失，词义任务只登记语境线索、不判正误，也不据此标记完整掌握。
- 12 词新增 48 个 MP3：每词包含英式 Sonia、美式 Ava 的单词音频与配套句音频。错误或跳过后，至少间隔 3 个其他任务，并经过约 5 分钟或累计约 300 秒练习量才无提示回测；全部训练共用每日 720 秒预算。
- 急救进度、失败、跳过和待回测队列只保存在当前浏览器的 `localStorage`，不上传学生答案或身份信息；换设备不会自动同步。

- 86 个学生自报薄弱词：原 50 词加 2026-08-01 听力新批次 36 词；原批次已剔除 3 个专名
- 21 份目标词表 PDF 与 36 条学生听力生词已整理为 12,352 条目标来源记录、7,242 个去重学习词条
- 21 份补充 PDF 与 2 份 DOCX 已抽出 15,523 条候选来源记录，统一去重为 11,092 条编辑复核行；候选词不会绕过教师审核进入学生词库

- 词库可按听、说、读、写主分类、词性、CEFR 与图片队列筛选；大词库只在打开时载入
- 同一个词连续通过“声音 → 图义（有审核图片时）→ 撤图听写 → 词形与构词 → 搭配到标准句复现”，不再把图像学习和四项核心能力完全分开

- 专项模块作为错误修复站：按听辨、拼写、词形、搭配／句法和意义混淆分别补练，再回到完整学习链
- 固定英美神经语音：单词读三遍，英美例句各一遍
- 听写支持播放／暂停／继续、正常与慢速重播、无答案逐级提示和稍后复习
- 句子工坊先进行无提示搭配回忆，再完成无大小写提示的词块排序与隐藏标准句复现；其他表达只保存为待人工评阅草稿
- 图像词义实验室：30 幅网页压缩手绘场景，覆盖词性入门、四格词族、近义词、反义词、同音词、同形词及语义分类
- 65 个经编辑视觉任务：12 组看图词族变形，以及猜词、近反义、同音、同形多义、类比、分类与上下义、固定搭配；其中 11 个看图辨义题已接入核心学习链
- 每组词族通关后解锁“四格故事复述”和经词典核实的词源卡，明确区分历史词源、想象记忆镜头与现代构词规则

- 学习记录保存在当前浏览器，可导入、导出并离线使用

## 功能

- **两种模式**：📋 列表 / 🂠 卡片（Anki 式，点击翻面）
- **正面** = 英文单词 + 英文例句；**背面** = 中文释义 + 中文例句
- **四个显示开关**：单词英 / 单词中 / 例句英 / 例句中 —— 可任意隐藏，用于默写自测
- **每卡错误计数** `错 − N ＋`：手动记录听写错误次数，**存在浏览器本地**（换设备不同步）
- **按错误次数排序**（多 → 前），配合「↻ 重排 / 清空计数」
- **四种音频**：单词·英 / 单词·美 / 例句·英 / 例句·美；每个单词读 **3 遍**，开头留白，避免被播放器切掉
- **测试练习**：根据掌握度安排复习，并提供中考常见题型
- **听写射击**：Phaser 4 Canvas 游戏，包含四波有限任务、三档难度、目标优先级、连击计分、动态难度、护盾和错题回写
- **响应式操作**：桌面与手机均可使用；支持点击目标、键盘输入、Tab 切换/重听和 Esc 暂停

## 语音

## 本地开发

需要 Node.js 22 或更新版本。

```bash
npm install
npm run dev
```

常用质量检查：

```bash
npm test          # Vitest 游戏规则测试
npm run lint      # ESLint
npm run test:e2e  # Playwright 桌面与手机冒烟测试
npm run build     # TypeScript 检查 + 生产构建
python3 -m unittest discover -s tests/corpus -p "test_*.py" -v  # 语料来源与状态门禁
python3 -m unittest discover -s tests/audio -p "test_*.py" -v   # 音频文本与资产绑定门禁
```

推送到 `main` 后，GitHub Actions 会完成测试、构建并部署 `dist/` 到 GitHub Pages。

## 内容约束

沪教版词汇知识库必须严格依据官方教材词表维护，不使用 AI 自行补全或推断教材词条。IELTS 词库保留用户提供 PDF 的来源证据；同音、同形、近反义、类比和上下义关系经证据或人工审核后才能进入正式题目。候选词不得直接生成游戏答案，游戏也不得改变来源词汇。

已登记的 46 份补充词汇教学资源将按批次用于提炼练习顺序、构词、搭配、记忆和测评方法；登记、文本抽取和候选词生成均不等于内容已经仔细评估。儿童教材、校本教材、SSAT 及第三方考试资料不作为 IELTS 目标词表的权威来源，也不复制原书图片、例句或整套练习。完整策略见 [`docs/integrated-vocabulary-learning-loop.md`](docs/integrated-vocabulary-learning-loop.md)，协作和验收规则见 [`docs/agent-operating-model.md`](docs/agent-operating-model.md)。
