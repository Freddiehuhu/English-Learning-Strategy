# English Learning Strategy · 沪教版八年级上册 单词/短语 学习卡

一个面向初中生的英语学习网页应用：**267 条**词汇（单词 203 + 短语 64），自带**自然语音音频**、**中英对照例句**、**Anki 式卡片**、**掌握度练习**与基于 Phaser 的**听写射击任务**。

> 📖 教材：上海教育出版社《英语》八年级上册（Units 1–8）。教材词汇表以**英式发音**为标准。

## 功能

- **两种模式**：📋 列表 / 🂠 卡片（Anki 式，点击翻面）
- **正面** = 英文单词 + 英文例句；**背面** = 中文释义 + 中文例句
- **四个显示开关**：单词英 / 单词中 / 例句英 / 例句中 —— 可任意隐藏，用于默写自测
- **每卡错误计数** `错 − N ＋`：手动记录听写错误次数，**存在浏览器本地**（换设备不同步）
- **按错误次数排序**（多 → 前），配合「↻ 重排 / 清空计数」
- **四种音频**：单词·英 / 单词·美 / 例句·英 / 例句·美；每个单词读 **3 遍**，开头留白，避免被播放器切掉
- **测试练习**：根据掌握度安排复习，并提供中考常见题型
- **听写射击**：Phaser 4 Canvas 游戏，包含四波有限任务、三档难度、目标优先级、连击计分、动态难度、护盾和错题回写
- **响应式操作**：桌面与手机均可使用；支持点击目标、键盘输入、Tab 切换/重听和 Esc 暂停

## 本地开发

需要 Node.js 22 或更新版本。

```bash
npm install
npm run dev
```

常用质量检查：

```bash
npm test          # Vitest 游戏规则测试
npm run lint      # ESLint
npm run test:e2e  # Playwright 桌面与手机冒烟测试
npm run build     # TypeScript 检查 + 生产构建
python3 -m unittest discover -s tests/corpus -p "test_*.py" -v  # 语料来源与状态门禁
python3 -m unittest discover -s tests/audio -p "test_*.py" -v   # 音频文本与资产绑定门禁
```

推送到 `main` 后，GitHub Actions 会完成测试、构建并部署 `dist/` 到 GitHub Pages。

## 内容约束

沪教版词汇知识库必须严格依据官方教材词表维护，不使用 AI 自行补全或推断教材词条。IELTS 词库保留用户提供 PDF 的来源证据；同音、同形、近反义、类比和上下义关系经证据或人工审核后才能进入正式题目。候选词不得直接生成游戏答案，游戏也不得改变来源词汇。

已登记的 46 份补充词汇教学资源将按批次用于提炼练习顺序、构词、搭配、记忆和测评方法；登记、文本抽取和候选词生成均不等于内容已经仔细评估。儿童教材、校本教材、SSAT 及第三方考试资料不作为 IELTS 目标词表的权威来源，也不复制原书图片、例句或整套练习。完整策略见 [`docs/integrated-vocabulary-learning-loop.md`](docs/integrated-vocabulary-learning-loop.md)，协作和验收规则见 [`docs/agent-operating-model.md`](docs/agent-operating-model.md)。
